# Bootstrap Reference

## Grid System
- 12-column responsive grid.
- Containers: `.container` (fixed), `.container-fluid` (full width).
- Rows: `.row` to wrap columns.
- Columns: `.col-{breakpoint}-{size}`.
- Breakpoints: `xs`, `sm`, `md`, `lg`, `xl`, `xxl`.

## Components
- `.alert` - Alert messages (`.alert-success`, `.alert-danger`, etc).
- `.badge` - Badges and labels.
- `.btn` / `.btn-primary` - Buttons.
- `.card` - Content cards.
- `.form-control` - Form inputs.
- `.table` / `.table-striped` - Tables.
- `.modal` - Modal dialogs.
- `.nav` / `.navbar` - Navigation.
- `.pagination` - Pagination.
- `.dropdown` - Dropdown menus.

## Utilities
- `.d-flex`, `.d-none`, `.d-md-block` - Display.
- `.mt-*`, `.mb-*`, `.p-*` - Spacing (0-5).
- `.text-center`, `.text-right` - Text alignment.
- `.bg-primary`, `.text-white` - Colors.
- `.w-100`, `.h-100` - Sizing.
- `.rounded`, `.shadow` - Effects.

## Best Practices
- Use Bootstrap utility classes before custom CSS.
- Keep consistent spacing using the spacing scale.
- Mobile-first: design for xs first, then larger.
