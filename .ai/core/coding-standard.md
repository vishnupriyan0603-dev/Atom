# Coding Standards

## PHP (PSR-12)
- PSR-1: Basic coding standard.
- PSR-4: Autoloading.
- PSR-12: Extended coding style guide.

### Naming Conventions
- Classes: `PascalCase`
- Methods/Functions: `camelCase`
- Properties: `camelCase` or `$snake_case` (framework-dependent)
- Constants: `UPPER_SNAKE_CASE`
- Interfaces: `InterfaceName` suffix
- Abstract classes: `Abstract` prefix

### Code Style
- 4 spaces for indentation (no tabs).
- Line length: 120 characters soft limit, 80 recommended.
- Opening brace on same line for classes/methods.
- One statement per line.
- No trailing whitespace.

## JavaScript
- Variables: `camelCase`
- Classes: `PascalCase`
- Constants: `UPPER_SNAKE_CASE`
- 2 spaces for indentation.
- Semicolons required.

## SQL
- Keywords: `UPPER_CASE`
- Table/Column names: `snake_case`
- Always alias tables with meaningful abbreviations.
- Write explicit column lists, never `SELECT *`.
